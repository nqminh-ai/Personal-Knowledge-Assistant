PHÂN CÔNG CHI TIẾT — 12 TUẦN × 5 VAI TRÒ

Ai làm gì, tuần nào — Personal Knowledge Assistant

Chi tiết hoá mục 12–13 của Proposal v2 thành đầu việc cụ thể cho từng người mỗi tuần. Dùng trực tiếp làm task board (Trello/GitHub Projects) — mỗi gạch đầu dòng là một task có thể tick.

Tuần 01

Scoping

GateApproved proposal + data plan
A — Data
  • Khảo sát tài liệu nhóm đang có sẵn (slide, giáo trình, notes) — lập danh sách nguồn
  • Draft kế hoạch thu thập corpus: số lượng tài liệu mục tiêu, định dạng, nguồn bổ sung nếu thiếu
B — Retrieval
  • Research 2-3 embedding model tiếng Việt/đa ngôn ngữ ứng viên (vd bge-m3, Vietnamese-SBERT)
  • Research FAISS vs Qdrant, chọn phương án MVP
C — LLM/RAG
  • Research LLM API ứng viên theo tiêu chí quality/cost/latency
  • Viết draft system prompt v0 (grounded + abstention rule)
D — Eval & FE
  • Research RAGAS, NLI-based faithfulness scoring
  • Draft schema evaluation set (question, gold answer, gold chunk, query_type)
E — PM/QA
  • Hoàn thiện & nộp đề cương xin duyệt; chốt RQ và giả thuyết
  • Setup GitHub repo, cấu trúc thư mục, task board
Sync cuối tuần: thống nhất embedding model + LLM API sẽ dùng cho MVP; xác nhận corpus plan khả thi.
Tuần 02

Data & QA seed

GateCorpus v0 + QA seed v0
A — Data
  • Thu thập tài liệu thật từ nhóm, tổ chức theo doc_id/thư mục
  • Ghi metadata ban đầu: filename, loại tài liệu, nguồn, số trang
B — Retrieval
  • Sanity-check 2-3 embedding model trên vài đoạn mẫu (similarity thủ công)
  • Chốt embedding model cho MVP dựa trên kết quả sanity check
C — LLM/RAG
  • Viết prompt template v1 cho generation + định dạng citation
  • Test gọi thử LLM API, đo latency/cost cơ bản
D — Eval & FE
  • Setup Label Studio với schema đã chốt
  • Viết 30-50 câu QA seed (pilot) từ tài liệu đã thu thập
E — PM/QA
  • Review chất lượng/độ đa dạng corpus thu thập được, bổ sung nếu thiếu ngành/loại
  • Review 30-50 câu QA seed, góp ý sửa trước khi dùng làm test v0
Sync cuối tuần: corpus đủ đa dạng để bắt đầu ingestion chưa? QA seed đã rõ ràng, không mơ hồ chưa?

Tuần 04

Chunking + Embedding

GateRetrieval demo v0 (chưa generation)
A — Data
  • Hoàn thiện metadata schema đầy đủ
  • Xử lý cleaning noise (loại ký tự rác, giữ thông tin có nghĩa)

  • Implement 3 chiến lược chunking (256/512/1024 token)
  • Build dense embedding index cho toàn bộ corpus

  • Nối demo query → top-k chunk (chưa generation) để kiểm tra retrieval thô
D — Eval & FE
  • Viết script đo recall@k trên QA seed cho từng chunk size
E — PM/QA
  • Review chất lượng chunk thủ công, chốt chunk size mặc định cho MVP
Sync cuối tuần: chunk size nào cho recall@k tốt nhất trên QA seed? Chốt cấu hình mặc định.
Tuần 05

Dense RAG (S1) + BM25 (S2)

GateS1 chạy end-to-end; S2 index sẵn sàng
A — Data
  • Tích hợp word segmentation tiếng Việt (underthesea/pyvi) vào pipeline tiền xử lý
B — Retrieval
  • Implement BM25 index (rank_bm25/Elasticsearch) trên corpus đã segment → S2
  • Hoàn thiện Dense retrieval production-ready → S1
C — LLM/RAG
  • Nối LLM generation với Dense retrieval context → chạy end-to-end S1
  • Hoàn thiện grounded prompt v1 (bám evidence, có abstention)
D — Eval & FE
  • Unit test: tokenizer cho cùng input phải ra cùng token ở cả pipeline index và query
  • Viết script đo metric baseline sơ bộ (EM/F1) trên QA seed
E — PM/QA
  • Review kết quả S1 pilot, họp mid-sprint điều chỉnh nếu cần
Sync cuối tuần: S1 end-to-end có chạy ổn định không? Tokenizer unit test có pass không — đây là điểm dễ lỗi ngầm nhất.

Tuần 08

Eval set hoàn chỉnh

Gate280-320 câu, Kappa ≥ 0.6, config freeze
A — Data
  • Hoàn thiện corpus final nếu còn thiếu
B — Retrieval
  • Freeze cấu hình retrieval (embedding model, chunk size, K) cho benchmark chính thức
C — LLM/RAG
  • Freeze prompt template + generation config
D — Eval & FE
  • Hoàn thiện evaluation set lên 280-320 câu (45+/loại query)
  • Thực hiện cross-review 20% mẫu, tính Cohen's Kappa
E — PM/QA
  • Điều phối annotation, giải quyết bất đồng gán nhãn, đảm bảo Kappa đạt ngưỡng ≥0.6
Sync cuối tuần: Kappa đạt ngưỡng chưa? Nếu chưa — tổ chức thảo luận thống nhất tiêu chí trước khi sang tuần 9. Mọi config đã freeze chưa (bắt buộc trước khi chạy full benchmark).
